# Hestia v0.5

Mobile-first shared planner PWA using its own Firebase project and the Chronos-style `dashboards/{uid}` Firestore document.

Read `SETUP.md` to configure Firebase, enable Google sign-in, publish Firestore rules, and deploy to GitHub Pages.

Google account sign-in and live calendar sync are implemented in the website; Android background push notifications still require separate server-side work.
